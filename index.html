🎨 1. تصميم الواجهة (Frontend)

الواجهة هي اللي كيشوفها المستخدم. في iStore، استعملنا تقنية Glassmorphism (الزجاجية) و Dark Mode (الوضع الداكن) باش نعطيو ستايل iOS 26.

مثال حي: كارت التطبيق (App Card)
هذا كيفاش يبان كارت التطبيق في الموقع. استعملنا Flexbox باش نرتبو الأيقونة والنص والزر:

🔥 3. قاعدة البيانات (Firebase)

كيفاش كتخزن التطبيقات؟ في iStore استعملنا Firebase من Google. هذا المخطط كيوضح كيفاش الموقع كيتواصل مع السيرفر:

📱 واجهة المستخدم (HTML/JS)
⬇️ ⬆️
☁️ Firebase Firestore (قاعدة البيانات)
⬇️ ⬆️
🖼️ الصور والملفات (روابط مباشرة)

باش نجيبو التطبيقاتالك من Firebase في الجافاسكريبت، كنستعملو هذا الكود:

// كود JavaScript
import { getFirestore, collection, getDocs } from "firebase/firestore";

const db = getFirestore(app);

async function loadApps() {
    const querySnapshot = await getDocs(collection(db, "apps"));
    querySnapshot.forEach((doc) => {
        console.log(doc.data().name); // يطبع اسم التطبيق
    });
}

🤖 4. المساعد الذكي (isto)

في iStore، كاين روبوت ذكي (isto) كيجاوب على أسئلة المستخدمين. هذا كيتصنع باستعمال API (واجهة برمجة تطبيقات) ديال الذكاء الاصطناعي.

🤖

👤
كيفاش نحمل تطبيق؟

باش تصنع روبوت كيقرا ويكتب، كتربط الموقع ديالك بـ API بحال OpenAI:

async function askAI(message) {
    const response = await fetch("https://api.openai.com/v1/chat/completions", {
        method: "POST",
        headers: {
            "Authorization": "Bearer YOUR_API_KEY",
            "Content-Type": "application/json"
        },
        body: JSON.stringify({
            model: "gpt-3.5-turbo",
            messages: [{ role: "user", content: message }]
        })
    });
    const data = await response.json();
    return data.choices[0].message.content;
}
